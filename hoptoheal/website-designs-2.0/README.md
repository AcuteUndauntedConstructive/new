# Hop to Heal 2.0 — website design source

Source files for the "Hop to Heal 2.0" Claude Design canvas (16 boards).
Each `project/*.dc.html` file is one board; `project/canvas.json` is the layout index.

| Row | Boards |
| --- | --- |
| Public site | Main, Services, Counselling |
| HopCheck 2.0 | HopCheck (hub), ParentCheck (grown-up check), KidCheck (child's "My turn!"), Result, QuestionBank |
| Sign in, book, pay | SignIn, Book, Pay |
| Portals | Parent, Child, Therapist, Update |
| Internal | TestPlan (tester checklist) |

Prices used: therapy ₹800 per 1-hour session per child; 15-day pack ₹9,600 (15 sessions);
counselling ₹500 per 30-minute session per person, online (Google Meet, link 5 minutes before) or at the centre;
21-day counselling plan ₹8,400 (assumed 21 sessions at 20% off).

Image and script paths starting with `/_blob/` are canvas-hosted assets; the originals are in `../assets/`.
The earlier designs are untouched.

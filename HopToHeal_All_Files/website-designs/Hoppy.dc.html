Hoppy always

  • Speaks Hindi and English

  • Asks consent before saving a child's details
  • Answers only from Hop to Heal's approved FAQs

Hoppy never

  • Diagnoses or labels a child
  • Gives medical or medicine advice
  • Shares or sells personal data
  • Pressures a parent to buy
  • Plays sound without a tap

Build notes for the animator

  • Chat button is built: the mascot-chatbot widget (SVG + CSS, no library) with closed, open and thinking states. See the "Hoppy chat widget" board.
  • Extra moods (wave, celebrate, sleepy) can be added later as more states, or moved to one Rive file if we want richer motion
  • Layers to rig: body, 3 rays, eyes (closed / open / happy / sleepy), mouth (w / smile / open / o), cheeks
  • Calm mode and "reduce motion" settings freeze Hoppy on the Idle pose
